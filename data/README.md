### Feature set and protected-attribute exclusions (PRD F9.9)

Final feature list fed to the model — 17 columns, matching the `employees` table in `Architecture.md` (locked at Phase 8) exactly: `age`, `department`, `job_level`, `monthly_income`, `years_at_company`, `years_since_last_promotion`, `years_with_curr_manager`, `total_working_years`, `job_satisfaction`, `environment_satisfaction`, `relationship_satisfaction`, `performance_rating`, `overtime`, `business_travel`, `distance_from_home`, `percent_salary_hike`, `stock_option_level`.

**Excluded as protected attributes:** `Gender` and `MaritalStatus` are dropped entirely from the feature set — no proxy is retained for either.

**Age is a considered inclusion, not an oversight.** Raw `Age` is kept as a plain numeric feature: it is already part of the `employees` table locked at Phase 8, and PRD F9.9 names "age **band**" as the excluded quantity, not age itself. No age-band or bucketed-age feature is engineered anywhere in this pipeline — that bucketing is the specific thing F9.9 calls out, and it does not exist at any stage from raw data to the serialised preprocessor (`ml/attrition/02_preprocessing.py`). If a stricter reading (excluding raw age too) is ever wanted, this is the line to change.

**Everything else excluded is unrelated to protected-attribute status:** `EmployeeNumber` (identifier, not a feature — the `employees.id` primary key replaces it), `EmployeeCount`/`Over18`/`StandardHours` (constant across all 1,470 rows — zero variance, verified directly), and `DailyRate`/`HourlyRate`/`MonthlyRate`/`Education`/`EducationField`/`JobInvolvement`/`JobRole`/`NumCompaniesWorked`/`TrainingTimesLastYear`/`WorkLifeBalance`/`YearsInCurrentRole` (not part of the `employees` schema locked at Phase 8).

**Class balance:** 237 Yes / 1,233 No (16.12% / 83.88%), roughly a 5.2:1 imbalance. Not addressed in Phase 9 — Phase 10 handles it via `class_weight="balanced"` and a resampling comparison (F9.4).

Full column-by-column EDA, including the six PRD F9.2 attrition-rate breakdowns and the class-balance chart, lives in `ml/attrition/01_eda.ipynb`.
